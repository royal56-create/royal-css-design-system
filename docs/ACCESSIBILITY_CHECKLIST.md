# CSS Accessibility Checklist

- [ ] Keyboard focus is visible.
- [ ] Text and interface colors have adequate contrast.
- [ ] Color is not the only way information is conveyed.
- [ ] Motion respects `prefers-reduced-motion`.
- [ ] Text remains usable at 200% zoom.
- [ ] Layout works with longer text and user font settings.
- [ ] Form controls have visible, programmatic labels.
- [ ] Hover-only information also works with keyboard focus.
- [ ] Content order remains logical when layout changes.
