# Modern CSS Features Reference

| Feature | Use | Example in this repository |
|---|---|---|
| Custom properties | Shared tokens | `assets/css/tokens.css` |
| Flexbox | One-dimensional layout | `examples/layout/flexbox.html` |
| Grid | Two-dimensional layout | `examples/layout/grid.html` |
| clamp()/min()/max() | Fluid sizing | `examples/advanced/css-functions.html` |
| Logical properties | Writing-mode-aware spacing | `examples/advanced/logical-properties.html` |
| Nesting | Group related rules | `examples/advanced/css-nesting.html` |
| Container queries | Component-level responsiveness | `examples/advanced/container-queries.html` |
| Cascade layers | Explicit cascade organization | `examples/advanced/cascade-layers.html` |
| Scroll snap | Scroll position alignment | `examples/layout/scroll-snap.html` |
| Print media | Paper-friendly output | `examples/advanced/print-styles.html` |

Feature availability varies by browser version. Check current support and retain fallbacks where needed.
