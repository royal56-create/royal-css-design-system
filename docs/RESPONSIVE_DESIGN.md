# Responsive Design Checklist

- Include the viewport meta tag.
- Prefer fluid sizing and intrinsic layouts.
- Use Grid/Flexbox and flexible tracks.
- Add breakpoints when content requires them, not for device names.
- Check narrow screens and large text zoom.
- Prevent horizontal overflow and clipped focus rings.
- Test long labels, translated text and empty states.
- Keep touch targets comfortably sized.
