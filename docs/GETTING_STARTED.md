# Getting Started

No build tools or dependencies are required. Open `index.html` in a modern browser. For a local server, run `python -m http.server 8000` from the repository root and visit `http://localhost:8000`.

## Structure
- `assets/css/`: shared tokens, reset, base, layout, components, utilities and themes.
- `examples/`: focused standalone demonstrations.
- `docs/`: learning and contribution guides.
- `tests/`: dependency-free integrity checks.

## Learning sequence
1. Selectors, cascade and specificity.
2. Box model, units, colors and typography.
3. Flexbox, Grid and responsive layouts.
4. Design tokens and reusable components.
5. Themes, motion, accessibility and advanced CSS.

Inspect each example and change one declaration at a time.
