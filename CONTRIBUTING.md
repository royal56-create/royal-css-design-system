# Contributing

1. Keep examples focused and independently understandable.
2. Use semantic HTML and accessible names.
3. Prefer tokens and reusable classes over duplicated values.
4. Include responsive behavior and visible focus styles.
5. Respect reduced-motion preferences.
6. Avoid unjustified external dependencies.
7. Run `node tests/check-project.mjs` before submitting changes.
8. Document new examples in the relevant guide or catalog.
